# 魔法陣 — マウスジェスチャー・ショートカットランチャー

右クリックを押しながら画面をなぞると、その軌跡に対応するショートカットキーを発動する Windows 常駐アプリです。
なぞっている間は画面全体にクリック透過のオーバーレイが重なり、始点に魔法陣、指の軌跡に発光する線、
そして認識中のコマンド名が表示されます。発動すると魔法陣が展開して消えます。

## 動かす

```bash
dotnet build MagicCircle.csproj -c Release
```

## 別の PC へ配布する

通常のビルドで作られる `MagicCircle.exe` を実行するには、配布先の PC に
64 bit 版の .NET 6 Desktop Runtime が必要です。

ランタイムを別途インストールせずに実行できる配布物を作る場合は、
`配布用ビルド.bat` を実行してください。生成された
`配布用\MagicCircle-win-x64.zip` を配布先へコピーして展開し、
展開先の `MagicCircle.exe` を起動します。

ビルド後、`bin\Release\net6.0-windows\MagicCircle.exe` を起動するとタスクトレイに常駐します。
`起動.bat` をダブルクリックすれば、ビルドと起動をまとめて行います。

- タスクトレイのアイコンを右クリック → 有効/無効の切り替え、デザイン切り替え、設定画面、再読み込み、終了
- アイコンをダブルクリック → 設定画面を開く

## 使い方

1. どこでもよいので **右ボタンを押したまま** マウスを動かす
2. 画面に魔法陣と軌跡が出る。判定中のコード（例 `↓→`）と対応コマンド名が軌跡の先に表示される
3. **右ボタンを離すと発動**する

## コマンドヘルプ

なぞる手を **約 0.4 秒止める** と、いまの位置の周りに「次にどの方向へ進むと何になるか」が 8 方位で浮かびます。
動かすと消え、止めるとまた出ます。

- 描き始めた直後（まだ方向が確定していないうち）は、1 ストローク目のコマンドが 8 方位に並びます
  （例: `↑ ウィンドウ最大化 ＋3` — その方向にはさらに 3 つの続きがある、という意味）
- 1 画引いてから止めると、**その続きの候補だけ**に絞られてカーソルの周りへ移動します
  （例: 下へ引いて止めると `→ 貼り付け` `↑ 再読み込み` `← コピー`）
- `…` から始まる項目は、もう 1 画以上必要なもの（`…設定を開く` = あと数画で確定）

`settings` の `showCommandHelp` を `false` にすると出なくなり、`commandHelpDelayMs` を `0` にすると
描き始めた直後から出ます。

右ボタンを押しただけ（32px 未満しか動かさなかった場合）は、通常の右クリックとして元のアプリにそのまま渡されます。
コンテキストメニューは押した時ではなく離した時に出ます。

## 途中でやめる

右ボタンを押したまま **左クリック（または中クリック）** すると、その場でジェスチャーが中止されます。
軌跡と魔法陣は即座に消え、そのあと右ボタンを離してもショートカットは発動しません。

中止に使った左／中クリックは魔法陣が握り潰すので、**カーソルの下にあるボタンやリンクを押してしまうことはありません**
（押下と解放の両方を止めています。ジェスチャー中でない普通のクリックはこれまでどおり動きます）。

なお Esc キーは効きません（マウスのみを監視しているため）。

## デザインを切り替える

トレイアイコンを右クリック →「デザイン」から、オーバーレイの見た目を 3 種類から選べます。
選んだ瞬間に切り替わり（次に描くジェスチャーから反映）、`gestures.json` の `designStyle` にも保存されます。

| デザイン | `designStyle` | 見た目 |
|----------|---------------|--------|
| 魔法陣 | `arcane` | 既定。二重円・24 本の目盛り・六芒星・逆回転する外弧 |
| ミニマル | `minimal` | 細い円と 4 方向の目盛りだけ。装飾を削り、軌跡そのものを見せる |
| HUD | `hud` | 角ブラケット・8 分割の回転リング・クロスヘアの照準器風 |

軌跡やラベルの太さ・パネルの形もデザインごとに変わります。
`themeColor` / `accentColor` はどのデザインでも共通に効くので、色は別途好みに変えられます。

## 標準のジェスチャー

| 軌跡 | コマンド | 送出キー |
|------|----------|----------|
| `←` | 戻る | `alt+left` |
| `→` | 進む | `alt+right` |
| `↑` | ウィンドウ最大化 | `win+up` |
| `↓` | ウィンドウ最小化 | `win+down` |
| `↓→` | タブを閉じる | `ctrl+w` |
| `↑→` | 新しいタブ | `ctrl+t` |
| `↑←` | 閉じたタブを復元 | `ctrl+shift+t` |
| `↓↑` | 再読み込み | `f5` |
| `↑↓` | 貼り付け | `ctrl+v` |
| `↓←` | コピー | `ctrl+c` |
| `←→` | タスクビュー | `win+tab` |
| `→←` | デスクトップ表示 | `win+d` |
| `↖` | 範囲スクリーンショット | `win+shift+s` |
| `↗` | 検索 | `win+s` |
| `↘` | 元に戻す | `ctrl+z` |
| `→↓←↑` | 設定を開く | `win+i` |

## ジェスチャーを追加・変更する（設定画面）

タスクトレイのアイコンをダブルクリック（または右クリック →「ジェスチャー設定を開く…」）すると設定画面が開きます。
JSON を書かずに割り当てを変えられます。

1. 一覧から行を選ぶと、下の編集欄に読み込まれます
2. **ジェスチャー**は「描いて登録」を押してから、画面を実際に右ドラッグすると取り込まれます
   （矢印ボタンでの手入力、「1つ消す」「クリア」も使えます）
3. **キー**は「キーを押して登録」を押してから、使いたい組み合わせを実際に押すと取り込まれます
   （取り込み中はキー入力を横取りするので、`win+d` のような OS のショートカットが暴発しません。`Esc` で中止）
4. 「新規追加」「選択行を更新」「選択行を削除」で一覧を編集し、最後に **「保存」** を押すと `gestures.json` に書き込まれ、即座に反映されます

- 「キャンセル」で閉じれば変更は破棄されます（保存するまでファイルには触れません）
- ジェスチャーが他の行と重複している、キーが解釈できない、コマンド名が空、といった場合は保存前に赤字で知らせます
- 設定画面から保存すると、`gestures.json` 内のコメントは失われます

## 設定ファイルを直接編集する

トレイメニューの「gestures.json を直接開く」でも編集できます。編集後は「設定を再読み込み」を実行してください。

```json
{ "gesture": "↓←↑", "name": "全画面", "keys": "f11" }
```

- **gesture**: 矢印 `↑ ↓ ← → ↖ ↗ ↙ ↘` を並べる。テンキー表記（`8 2 4 6 7 9 1 3`）でも書けます（`"26"` = `"↓→"`）。
- **keys**: `+` で同時押し、`|` で連続送出（例 `"ctrl+c|ctrl+v"`）。
  - 修飾子: `ctrl` / `shift` / `alt` / `win`
  - 主キー: `a`-`z`, `0`-`9`, `f1`-`f24`, `enter`, `esc`, `tab`, `space`, `backspace`,
    `delete`, `insert`, `home`, `end`, `pageup`, `pagedown`, `left`, `up`, `right`, `down`,
    `numpad0`-`numpad9`, `volumeup`, `volumedown`, `mute`, `medianext`, `mediaprev`,
    `mediaplay`, `printscreen`, および記号キー ``; = , - . / ` [ \ ] '``

### 判定の調整（settings）

| 項目 | 既定 | 意味 |
|------|------|------|
| `segmentSampleDistance` | 26 | 方向を判定する間隔(px)。小さいほど細かい曲がりを拾う |
| `minSegmentLength` | 48 | これより短い区間は雑音として捨てる(px)。誤爆が多いなら大きくする |
| `minGestureDistance` | 32 | これ未満なら通常の右クリックとして扱う(px) |
| `designStyle` | `arcane` | オーバーレイの見た目（`arcane` / `minimal` / `hud`）。→「デザインを切り替える」 |
| `themeColor` / `accentColor` | 紫 / 水色 | 魔法陣と軌跡の色。どのデザインでも共通に効きます |
| `showOverlay` | true | false にすると描画せず判定だけ行う |
| `showCommandHelp` | true | 手を止めたときに周囲へコマンドヘルプを出すか |
| `commandHelpDelayMs` | 400 | ヘルプを出すまでの静止時間(ms)。0 で描き始めた直後から出る |

## 仕組み

- `MouseHook.cs` — `WH_MOUSE_LL` で全画面のマウスを監視。右ボタン押下は一旦握り潰し、
  ジェスチャーでなかった時だけ `SendInput` で本来のアプリへ流し直す
- `GestureRecognizer.cs` — 軌跡を一定距離ごとに 45 度刻みで量子化し、同方向をまとめ、短い区間を捨てて `↓→` のような文字列にする
- `OverlayWindow.cs` — 仮想スクリーン全体を覆うクリック透過のレイヤードウィンドウ。
  DIB セクションに GDI+ で描き、`UpdateLayeredWindow` で毎フレーム転送する。
  配置とアニメーションの進行だけを持ち、実際の筆致は `OverlayStyle` に委ねる
- `OverlayStyle.cs` — オーバーレイの見た目 3 種類（`ArcaneStyle` / `MinimalStyle` / `HudStyle`）。
  陣・軌跡・先端・パネルの描き方と、半径などの寸法をスタイルごとに持つ
- `KeySender.cs` — キー指定を仮想キーコードに変換して `SendInput` で送出。設定画面向けに検証とキー名の逆引きも提供する
- `SettingsForm.cs` — ジェスチャー設定の GUI。編集は作業コピー上で行い、「保存」で初めてファイルへ書き出す
- `KeyboardCapture.cs` — 設定画面の「キーを押して登録」用。`WH_KEYBOARD_LL` で取り込み中のキーを握り潰す
- `magiccircle.ico` — 16〜128px の 7 サイズを同梱したアイコン。exe のアイコン（`ApplicationIcon`）と
  トレイアイコン（埋め込みリソースから表示サイズに合うフレームを選択）の両方に使う

## 制限事項

- **キーはカーソル下のウィンドウではなく、フォーカスされているウィンドウに届きます。**
  別ウィンドウの上でなぞると、キーは今フォーカスのあるアプリに送られます。
- **管理者権限で動いているウィンドウ**（昇格したアプリ、タスクマネージャー等）の上では、
  UIPI によりフックもキー送出も効きません。必要なら魔法陣自体を管理者として実行してください。
- **右ボタンドラッグを自前で使うアプリ**（3D ビューアの視点回転、一部のゲーム等）とは競合します。
  その場合はトレイメニューで一時的に無効化してください。
- 二重起動はできません（フックの二重掛けを防ぐため）。

## 検証済みの動作

- ジェスチャー認識ロジック: 直線・L 字・四角・手ブレ・短い雑音区間を含む 17 ケースで期待どおり（`GestureRecognizer`）
- 実機での経路: マウス入力を注入して右ドラッグ `↓→` を再現し、フォーカス中のテストアプリが送出キーを受信することを確認
- 右クリック素通し: 動かさずに押して離すと、対象アプリのコンテキストメニューが表示されることを確認
